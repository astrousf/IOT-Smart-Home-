// The Challenge

Why Traditional Home Security
Falls Short

Conventional home security setups tend to be costly, complicated to install, and narrowly focused — built for surveillance alone, or access control alone, rarely both. As a result, homeowners often end up running several disconnected systems just to cover security, monitoring, and hazard detection, which drives up both cost and complexity. This project sets out to close that gap with a single, affordable platform that brings security, safety, and automation together in one integrated smart home system.

  • 💰
    Costly Add-Ons
    Separate alarms, cameras, and sensor kits each come with their own price tag, multiplying the total investment.
  • 🛠️
    Difficult Installation
    Many systems demand professional setup, wiring, and configuration before they're usable.
  • 🎯
    Single-Purpose Design
    A typical system covers either surveillance or access control — rarely both — leaving gaps elsewhere.
  • 🧩
    Disconnected Systems
    Running multiple independent platforms means multiple apps, logins, and points of failure.
// About the Project

An IoT & Computer Vision
Powered Mini-House

The Smart Home: An IoT and Computer Vision Powered Mini-House is a low-cost smart home system built to strengthen residential security, safety, and automation. It brings together access control, surveillance, environmental monitoring, and hazard detection in a single platform — powered by ESP32-based controllers and a dedicated set of sensors and actuators working in concert.

  • ✓ Develop a low-cost smart home security solution
  • ✓ Implement real-time monitoring and surveillance
  • ✓ Provide secure access control using RFID and keypad authentication
  • ✓ Detect motion, gas leaks, fire hazards, and temperature changes
  • ✓ Improve residential safety through automated alerts and responses

Everything a Smart Home
Needs to Stay Safe

Dual ESP32 Architecture

Two independent ESP32 controllers split the home into a Garage Control Unit and a Home Control Unit — each handling its own authentication, surveillance, and sensing, so the system keeps running smoothly across zones.

ESP32 · ESP32-CAM

RFID Access Control

Garage entry is secured with RFID RC522 authentication — only registered tags unlock the servo-driven garage door.

Keypad Authentication

The home entrance uses a numeric keypad for secure, code-based access control at the Home Control Unit.

Keypad

Real-Time Surveillance

ESP32-CAM

// System Flow

How It All Works Together

01

Authenticate

RFID at the garage and a keypad at the home entrance verify identity before any door opens.

02

Monitor

Dual ESP32-CAM modules stream live video while PIR, MQ-2, flame, and DHT11 sensors continuously sample the environment.

03

Detect

Each ESP32 evaluates sensor data for motion, gas leaks, fire risk, or temperature anomalies in real time.

04

Respond

On any hazard or unauthorized entry, the buzzer and alarm trigger automatically — with an average response time of 0.5 seconds.

// System Architecture

A Dual-Controller Network, Built for Coverage

Two independent ESP32 units divide the home into zones, each handling its own authentication, surveillance, and sensing — communicating over Wi-Fi for system-wide alerts.

  • 🚪
    ESP32 #1 — Garage Control Unit
    RFID (RC522) authentication, ESP32-CAM surveillance, servo-driven garage door, and a buzzer notification system
  • 🏠
    ESP32 #2 — Home Control Unit
    Keypad authentication, ESP32-CAM surveillance, PIR motion sensors, MQ-2 gas sensor, flame sensor, DHT11 temperature sensor, and servo-based door control
